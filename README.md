Excel VBA financial dashboard and Interface for analyzing company metrics and revenue trends.

## Features

- Interactive financial dashboard built in Excel
- UserForm interface developed with VBA for easy user interaction
- Automated financial data retrieval from the Financial Modeling Prep API
- Data transformation and cleaning using Power Query
- Dynamic Pivot Tables for financial analysis and reporting
- Automated data refresh and update process
- Structured data pipeline from API to dashboard visualization

## Technologies Used

- Microsoft Excel
- VBA (Visual Basic for Applications)
- Power Query
- Financial Modeling Prep API
- Pivot Tables
- Data Visualization in Excel
